Met dit programma kun je doolhofalgoritmes maken en testen in een simulatieomgeving.

LET OP ALS JE HET PROGRAMMA WILT TESTEN (STARTEN):
Het programma wijzigt automatisch bestanden.
Het programma kan bestanden verwijderen.
Het programma kan bestanden hernoemen.
Het programma kan bestanden aanmaken.
Het programma kan projecten starten (dus als je iets verkeerd programmeert, kan dit gevolgen hebben voor je bestanden).

DIT GELDT ALLEEN ALS HET PROGRAMMA GESTART WORDT, NIET ALS JE ALLEEN DE MAPPEN OP JE COMPUTER HEBT STAAN.


Handleiding

Om gebruik te maken van dit progamma moet er een sdk geinstalleerd worden (.NET 10 SDK).

1. Installeren en Starten
Pak het zip bestand uit en open verkenner in de map School-Ews-Project.
Klik op de adresbalk en typ cmd druk op enter.
Typ "dotnet run --configuration Release" en druk Enter.

2. Een project maken (HIERVOOR HEB JE DE SDK VOOR NODIG)
Klik op het plusje in het archief. er verschijnt een project map klik daar op. 
Nu zie je ondering het archief een naamgevings balkje geef je project een naam en druk op Enter.

3. Voor geprogameert algoritme gebruiken
je kan ook zonder een algoritme te schrijven het progama testen

maak eerst een project aan (volg stap 2).
Ga naar gedownloade repository naar AppProjects -> testingAlgoSandbox Kopieer hier alleen het bestand "program.cs".
Druk op Windows + R en voer het volgende pad in en druk enter.

vervang NAAMVANJEGEKOZEPROJECTMAP door de naam van je project map die je kort hiervoor had aangemaakt.
%APPDATA%\MazeIde\AppProjects\NAAMVANJEGEKOZEPROJECTMAP

Plak het program.cs bestand hier in en ga akkoord met de bestanden overschrijven.
Start de app weer op (volg stap 1)

4. Algoritme runnen en testen
Selecteer eerst je project keuze boven aan
Stel de groote van je Doolhof in en de batch size (hoeveel wil je dat er achter elkaar worden opgelost).
klik op de knop met het doolhoficoontje. (je zult eventueel voor een tijdje geen doolhof zien).
Klik op Run knop om het geselcteerde algoritme uit te voeren.
Waneer het lichtje van de run knop weer net als de andere knoppen is druk dan op de afspeel knop.

Met playspeed verander je de afspeelsnelhijd.
