KEYBINDS VOOR ZED - PERSONAL KEYS 2.1.1
========================================

Deze map is bedoeld om rechtstreeks in een project te zetten.
Gebruik Zeds bestandzoeker en zoek bijvoorbeeld op:

  cursor
  selecteren
  verwijderen
  classes
  tabs
  rename

Belangrijkste bediening
-----------------------

Gewone binding:
  Houd Alt vast en druk de actietoets in.
  Voorbeeld: Alt + I = één regel omhoog.

Binding met een tussenkey:
  1. Houd Alt vast.
  2. Houd de tussenkey vast.
  3. Druk de actietoets in.

Voorbeeld:
  Alt vasthouden + Z vasthouden + I = vijf regels omhoog.

NIEUW IN 2.1.1:
  Zodra je de tussenkey loslaat, is die laag direct uitgeschakeld.
  Alt mag ingedrukt blijven.

Dus:
  Alt + Z vasthouden + I = vijf regels omhoog
  Z loslaten, Alt vasthouden + I = één regel omhoog

Bij meerdere tussenkeys moeten ze allemaal ingedrukt blijven:
  Alt + A + S vasthouden + I = selectie/cursor boven toevoegen.

Notatie
-------

  Alt + Z + I

betekent in deze documentatie niet drie losse tikken. Houd Alt en Z vast
terwijl je I indrukt, tenzij uitdrukkelijk iets anders staat vermeld.
