PROJECTSIDEBAR
==============

TOETSEN                         ACTIE
------------------------------------------------------------------
Alt + [                         Sidebar tonen of focus geven
Alt + I                         Naar vorig item
Alt + K                         Naar volgend item
Alt + J                         Naar links / map inklappen
Alt + L                         Naar rechts / map uitklappen
Alt + F                         Nieuw bestand
Alt + R                         Nieuwe map
Alt + S vasthouden + D          Geselecteerd item hernoemen
Alt + ; vasthouden + -          Geselecteerd item naar prullenbak
Ctrl + Alt + Backspace          Alternatief: naar prullenbak

Context
-------

Alt+F maakt alleen een nieuw bestand wanneer de projectsidebar focus heeft en
je geen naam aan het bewerken bent. In de editor opent Alt+F juist de outline.

Alt+R maakt in de projectsidebar een map. In de editor zoekt Alt+R alle
referenties.
