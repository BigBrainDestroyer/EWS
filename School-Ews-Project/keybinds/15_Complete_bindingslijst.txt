COMPLETE EXACTE BINDINGSLIJST
=============================

Dit is de complete gebruikersgerichte lijst uit keymap.json van Personal Keys
2.1.1. De schrijfwijze links is dezelfde als in Zeds keymapbestand.

-------

alt-t                         -> terminalpaneel

alt-q                         -> projectsymbolen

alt-c                         -> kopiëren

alt-p                         -> regeleinde
delete                        -> Escape/cancel

alt-a alt-l                   -> rechts selecteren

alt-a alt-k                   -> omlaag selecteren

alt-a alt-m                   -> tot volgend subwoordeinde selecteren
alt-a alt-o                   -> tot regelbegin selecteren
alt-a alt-p                   -> tot regeleinde selecteren

alt-' alt-m                   -> volgend subwoord verwijderen

alt-d alt-k                   -> terug in navigatiegeschiedenis
alt-d alt-,                   -> actieve tab sluiten
alt-d alt-.                   -> gesloten tab heropenen
alt-z alt-i                   -> vijf regels omhoog
alt-z alt-k                   -> vijf regels omlaag

ctrl-alt-shift-k              -> terug in geschiedenis

ctrl-alt-shift-.              -> gesloten tab heropenen

TERMINAL
--------
alt-c                         -> terminal kopiëren

AUTOMATISCH TOEGEVOEGDE ZED-CONTEXTEN
-------------------------------------
alt-i                         -> vorige completion/code action/menu/signature
alt-k                         -> volgende completion/code action/menu/signature
alt-j                         -> menu parent of gewone editor links
alt-l                         -> menu child of gewone editor rechts
alt-i / alt-k in zoekbalk     -> vorige/volgende zoekopdracht

Niet zelf gebruiken
-------------------

De lange ctrl-alt-shift-a/b-reeksen in de gegenereerde keymap zijn interne
Personal Keys-codes. Ze zijn geen handmatige shortcuts en staan daarom niet in
de praktische bestanden.
