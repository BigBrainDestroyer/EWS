PROGRAMMA EN PANELEN
====================

TOETSEN                    ACTIE
-------------------------------------------------------------
Alt + B                    Command Palette openen/sluiten
Alt + T                    Terminalpaneel openen/sluiten
Alt + [                    Projectsidebar tonen/focus geven
Delete                     Escape/cancel sturen

Let op bij Delete
-----------------

De gewone fysieke Delete-toets is in deze keymap Escape/cancel. Gebruik voor
tekst rechts van de cursor:

  Alt + ' vasthouden + L

Terminal
--------

In de terminal gebruikt Alt+C de terminal-copyactie en Alt+V de
terminal-pasteactie. In de editor gebruiken dezelfde toetsen de gewone
editoracties.
