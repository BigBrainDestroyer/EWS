COMPLETION, MENU'S, PICKERS EN ZOEKGESCHIEDENIS
===============================================

Personal Keys maakt I/J/K/L contextafhankelijk zodat ze in heel Zed logisch
blijven werken.

Completion of code action zichtbaar
------------------------------------

Alt + I                    Vorige suggestie
Alt + K                    Volgende suggestie

Gewone picker of keuzelijst
---------------------------

Alt + I                    Vorig item
Alt + K                    Volgend item
Alt + J                    Naar parent/linkerkant
Alt + L                    Naar child/rechterkant

Signature help
--------------

Alt + I                    Vorige signature
Alt + K                    Volgende signature

Zoekbalk
--------

Alt + I                    Vorige zoekopdracht uit geschiedenis
Alt + K                    Volgende zoekopdracht uit geschiedenis

Gewone editor zonder popup
--------------------------

Alt + I                    Cursor één regel omhoog
Alt + K                    Cursor één regel omlaag
Alt + J                    Cursor links
Alt + L                    Cursor rechts

Hierdoor kiest Alt+I/K bij bijvoorbeeld de suggesties `mainboxa` en
`mainboxb` de suggestie, in plaats van de tekstcursor een regel te bewegen.
