TEKST VERWIJDEREN
==================

Tekens en woorden
-----------------

Houd Alt en de apostrof-toets ' vast:

TOETSEN                         ACTIE
------------------------------------------------------------------
Alt + ' + J                     Teken links verwijderen (Backspace)
Alt + ' + L                     Teken rechts verwijderen (Delete)
Alt + ' + N                     Vorig subwoord verwijderen
Alt + ' + M                     Volgend subwoord verwijderen

Extra:

Alt + Backspace                 Vorig woord/subwoord verwijderen

Hele regel verwijderen
-----------------------

Alt + ; vasthouden + -          Hele huidige regel verwijderen
Ctrl + Alt + Backspace          Direct alternatief

Projectsidebar
--------------

In de projectsidebar verwijdert dezelfde regelactie het geselecteerde bestand
of de geselecteerde map naar de prullenbak:

Alt + ; vasthouden + -
Ctrl + Alt + Backspace

Fysieke Delete-toets
---------------------

De gewone Delete-toets stuurt Escape/cancel. Gebruik voor Delete rechts van
de cursor daarom Alt + ' + L.
