TEKST SELECTEREN
================

Houd Alt en A vast terwijl je de laatste toets indrukt.

TOETSEN                         ACTIE
------------------------------------------------------------------
Alt + A + J                     Eén teken links selecteren
Alt + A + L                     Eén teken rechts selecteren
Alt + A + I                     Omhoog selecteren
Alt + A + K                     Omlaag selecteren
Alt + A + N                     Tot vorig subwoordbegin selecteren
Alt + A + M                     Tot volgend subwoordeinde selecteren
Alt + A + O                     Tot begin van de regel selecteren
Alt + A + P                     Tot einde van de regel selecteren
Alt + A + \                     Alles selecteren

Belangrijk
----------

Laat A pas los nadat de actietoets is uitgevoerd. Zodra A los is, stopt de
selectielaag. Als Alt ingedrukt blijft, werken I/J/K/L daarna weer als gewone
cursorbeweging.

Voorbeeld:

  Alt+A vasthouden + J          één teken links selecteren
  A loslaten, Alt vasthouden
  J                             cursor één positie links
